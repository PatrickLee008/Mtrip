##### 技术考量

- 认证服务
- 在超级管理员后台与商户端 App 认证服务之间同步各商户的登录方式状态。
- 支持由经授权管理员发起的会话立即吊销、待处理二维码登录失效，以及可信设备/生物识别信任撤销。
- 返回通用认证错误；除非受支持的支持流程需要更多细节，否则在管理视图中对关联的邮箱地址和手机号码保持掩码显示。
- 商户端 App 集成
- 用户端 App 集成
- 通知服务
- 分析服务
- 未来支付服务
- 审计日志
- PMS 集成服务
- 渠道管理器集成服务
- API 网关
- 配置管理服务
- 文件存储服务（商户文档）
- 监控与告警
- 集成日志
- 数据备份与恢复

将受支持的 mTrip 客户端应用与集中式 Guide Hub 服务/API 集成，以实现指南内容分发。超级管理员不属于 Guide Hub 内容管理流程的一部分。

指南的创建、元数据/配置、定向、排序、发布与维护由经授权的运营用户直接在 Guide Hub 中完成。

技术团队可使用模块 21 中列出的 Guide Hub 环境、API 文档、用户指南和开发者指南进行集成测试与验证。

客户端集成应遵循 Guide Hub API 支持的、并经工程团队确认的认证/授权、检索、错误处理、重试、监控及其他技术要求。

**餐厅数据核验与覆盖**

在第三方餐厅源数据（例如 Google Place ID/来源属性）与 mTrip 自有的核验状态、人工修正及列表可见性覆盖之间保持清晰分离。

面向用户的餐厅检索应应用 mTrip 的有效列表状态/覆盖，而不修改原始第三方源记录。

所有人工核验与覆盖操作必须受权限控制，并记录审计日志，包含变更前/变更后的值、原因、管理员及时间戳。
