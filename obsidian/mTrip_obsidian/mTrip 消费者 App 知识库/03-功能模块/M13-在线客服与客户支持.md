## 模块 13：实时聊天与客户支持

**概述**

客户支持聊天模块可在入住前、入住期间及入住后，为酒店预订相关咨询提供快速帮助。该模块首先通过聊天机器人/AI 助手处理常见问题。若问题仍未解决，用户可转接人工客服。聊天会话保持活跃，并可从“消息”中恢复。

**mTrip 客服聊天 – 入口**

用户可通过以下入口进入 mTrip 客服聊天：

- 酒店预订详情页：点击“人工客服聊天”按钮，打开 mTrip 客服聊天，获取与预订相关的帮助。
- 首页：点击标有“与我们聊天”的浮动聊天气泡，打开 mTrip 客服聊天。
- 更多 → 联系我们：点击“与 mTrip 聊天”，打开 mTrip 客服聊天。

### 目标

- 针对常见预订咨询提供快速自助支持。
- 通过自动回复降低客服工作量。
- 让用户快速获取与具体预订相关的支持。
- 提供无缝转接至人工客服的能力。
- 保留聊天记录，以支持持续会话。

### 客服模块功能需求

| 功能 | 需求 |
|---|---|
| 欢迎页 | 打开客服聊天时显示欢迎语。 |
| 预订选择 | 允许用户选择当前或历史预订，以获取与上下文相关的支持。 |
| 一般咨询 | 允许用户在不选择预订的情况下发起支持会话。 |
| 推荐问题 | 显示与所选预订或一般咨询相关的预置常见问题。 |
| 聊天机器人 | 针对常见客服问题提供自动回复。 |
| 人工客服 | 当需要进一步协助时，允许用户转接人工客服。 |
| 聊天记录 | 保存聊天记录，并允许用户继续此前的会话。 |
| 结束会话 | 允许用户结束当前支持会话。 |
| 反馈 | 允许用户在会话结束后对支持体验进行评分。 |
| 最近浏览的酒店 | 在客服过程中显示最近浏览的酒店，便于快速参考。 |

### 转接人工客服

用户可随时选择“联系客服”转接人工客服。系统还应在以下情况下建议转接：

- 聊天机器人无法回答用户的问题。
- 用户要求与人工客服沟通。
- 咨询涉及支付纠纷、投诉或特殊需求。
- 需要人工介入才能解决问题。

### 会话管理

- 用户退出聊天页面后，聊天会话应保持活跃。
- 用户可从“消息”板块继续此前的会话。
- 用户登录后，所有聊天记录应在用户的各设备之间同步。
- 用户可随时选择“结束会话”来结束支持会话。
