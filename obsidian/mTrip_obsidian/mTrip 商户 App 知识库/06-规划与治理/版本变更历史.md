### 变更历史

<!--TABLE_START-->
| 版本 | 日期 | 变更内容 |
| --- | --- | --- |
| 1.0 | 2026年8月14日 | 初版商户 App PRD，涵盖已定义的模块、需求和工作流。 |
| 1.0.1 | 2026年9月2日 | - 明确生物识别登录仅在商户移动 App 可用，商户 Web 门户不提供。<br>- 新增：商户使用商户访问码 + Google Authenticator 双因素认证完成首次登录后，可在商户移动 App 的“设置 > 安全”中启用可选的生物识别功能。<br>- 新增可信设备要求，并明确生物识别登录不需要额外的 KYC、活体检测或面部验证。<br>- 新增：同一登录会话内跨面部和指纹最多累计三次生物识别失败尝试，且以设备或操作系统限制为准。<br>- 新增：第三次生物识别失败、操作系统锁定、生物识别不可用，或商户选择“使用商户访问码”时，回退到商户访问码 + Google Authenticator 双因素认证。<br>- 新增：更换新设备、卸载重装应用、生物识别注册信息变更或相关安全变更时，需进行完整认证的要求。<br>- 明确商户 Web 门户支持商户访问码 + Google Authenticator 双因素认证，或通过已完成认证的商户移动 App 进行二维码登录。<br>- 更新了端到端注册、审批、首次登录、生物识别设置、后续移动端登录和 Web 门户登录流程图。 |
| 1.0.2 | 2026年9月8日 | - 新增 Google 账号（Gmail）+ mTrip OTP、注册邮箱 + 邮箱 OTP，以及注册手机号 + 短信 OTP 作为商户登录方式。<br>- 保留商户访问码 + Google Authenticator OTP 作为可选登录方式，并明确选择其他方式时不需要商户访问码。<br>- 确认二维码登录作为 Web 门户的一种内置登录方式，通过已完成认证的商户移动 App 实现，采用唯一、一次性、会过期的二维码并需在手机端明确确认。<br>- 更新了移动 App 与 Web 门户登录流程、生物识别回退、可信设备恢复、OTP 安全规则、功能需求、验收标准、安全设置、问答和认证流程图。<br>- 确定采用 6 位字符商户访问码，并与商户类型对应。<br>- 酒店商户访问码使用 HXXXXX；租车商户访问码使用 CXXXXX。<br>- 首位字符由商户类型固定。其余五个字符由系统使用 A-Z 或 0-9 生成。<br>- 确认每种商户类型有 60,466,176 种可能的组合。<br>- 新增前缀与商户类型的一致性校验，并更新认证要求、验收标准、问答和流程图。 |
| 1.0.3 | 2026年9月11日 | 根据已批准的设计和会议决议，更新了初始商户注册与 KYC 入驻流程。将手机号和电子邮箱设为必填；新增商户选择短信或邮件作为注册 OTP 发送方式；新增 OTP 验证后创建商户注册草稿、自动保存、进度跟踪和稍后继续的能力；从公司信息和业务详情中移除条款与条件的接受环节；新增 KYC 权限开放前的初始注册审核与审批；新增全屏条款与条件审阅、强制滚动到末尾、接受/拒绝处理、电子签名确认，以及“提交给管理员”的禁用/启用状态；明确了 KYC 审核、最终审批、商户访问码发放、申请状态、功能需求和业务规则与验收标准；将图 1 替换为最新的商户基本信息注册表单流程。图 2 的设置与登录流程、再次登录选项、Google/邮箱/短信 OTP 登录、二维码登录和生物识别要求保持不变。<br>- 新增 360 度酒店与房间媒体支持：商户移动 App 手机相机拍摄和相册选择；商户 Web 门户从电脑上传；提交前交互式预览；批准后向客户展示。<br>- 新增可选的房间级 VR/360 导览支持，使用受支持的安全 URL 或嵌入链接及封面缩略图。新增可选的可交互 3D 平面图支持，包括基础平面图上传、热点管理、预览、启用/停用状态、审核，以及批准后向客户展示。 |
| 1.0.4 | 2026年9月17日 | 新增了商户运营的同步错误场景与冲突处理要求。定义了 17 个同步/集成异常场景，涵盖支付、预订、库存、供应、取消、退款、价格、促销、预订修改、重复/乱序事件、服务/API 故障、房间映射以及批量更新部分成功。新增预订与批量封存并发规则：首个成功提交的库存事务为权威结果；若预订先提交，商户对该已预订库存的封存被拒绝；若封存先提交，用户端 App 重新校验并将房间显示为不可售。新增服务端供应重新校验、幂等性/事件排序要求、同步错误工作台行为、业务可读的同步告警以及相关验收标准。<br>- 在模块 10 – 商户支持与帮助中心下新增“用户指南与视频教程”，包括针对商户 App/Web 门户关键工作流的分类商户指引视频。新增“系统 > 支持”下的用户指南入口，以及跳转到同一用户指南模块的上部导航常驻“指南”快捷入口。新增相关验收标准，以及图文指南、常见问题和其他教学资源的未来扩展能力。 |
| 1.0.5 | 2026年9月24日 | 更新模块 10 – 商户支持与帮助中心，以与超级管理后台的支持工单管理保持一致。新增商户支持工单管理需求，涵盖工单创建（分类、优先级、主题、描述、可选附件）、唯一工单 ID、工单列表与汇总数量、搜索/筛选、面向商户的状态生命周期、指派支持专员、工单详情与会话/活动历史、商户回复、通知、RBAC，以及商户 App/Web 门户与超级管理后台之间的工单状态/回复同步。更新了相关验收标准和模块 10 的编号。 |
| 1.0.6 | 2026年9月28日 | 在模块 6 – 通知与设置下新增商户移动 App 账号注销申请流程。商户不能直接注销其商户账号；由已授权的主商户提交注销申请，交由超级管理员审批。新增已验证认证确认、「待超级管理员审批」状态、待审批申请的取消、超级管理员的批准/驳回处理、驳回原因显示、商户通知、审计历史，以及受适用的数据留存、法律、财务、预订、结算、审计与合规要求约束的注销获批处理。更新了相关验收标准。 |
| 1.0.7 | 2026年9月30日 | 根据修订后的出资决策，更新模块 8 – 促销与活动管理。移除商户自建的折扣百分比、固定金额减免和优惠码促销中商户侧的出资类型与共同出资配置。共同出资配置仍由超级管理员控制。新增平台定义的商户促销限额校验、受保护的最低应付金额、阻止 100% 免费/超限商户促销、带校验提示的提交拦截，并更新了相关验收标准。 |
| 1.0.8 | 2026年10月12日 | 从商户 Web 工作台和商户移动 App 移除 Google 社交/账号登录。保留注册邮箱 + 邮箱 OTP、手机号 + 短信 OTP、商户访问码 + Google Authenticator OTP、移动端生物识别登录和 Web 二维码登录。更新了登录要求与认证选项；UX/UI 将在两个平台上移除 Google 社交登录按钮。变更以青色突出显示。 |
| 1.0.9 | 2026年10月19日 | 使商户 PRD 与超级管理员 v1.0.8 的到店支付预订、基于佣金的交易手续费、由实际入住触发的结算完成、取消/未到店对账及相应验收标准保持一致。 |
| 1.0.11 | 2026年10月20日 | 修订模块 8 与促销验收标准：商户自费促销不再需要超级管理员审批；商户直接创建/编辑/启用/停用/结束促销；停用/结束时停止新的领取；对已领取权益保留原有条款及客户可见性/核销；超级管理员只读监控；更新设计中的移动端 UI 操作及审计要求。 |
| 1.0.12 | 2026年10月23日 | 更新了以下商户 PRD 章节：商务与支付设置、预订管理、支付管理、经营工作台与收益、结算与对账、活动与促销管理及相关验收标准。使商户侧的佣金与交易手续费可见性、到店支付资格、预订级配置快照及结算/对账与超级管理员 PRD 保持一致。确认到店支付/未到店规则：到店支付停用时，不进行商户房费预收；启用且未到店费用设为 FOC 时，仅预收 mTrip 佣金；启用且设置商户未到店费用时，预付金额包含 mTrip 佣金加上商户选定的房费预收，上限为房价的 30%。mTrip 佣金不与商户分成。新增商户针对 mTrip 创建及共同出资活动发起的提款申请，需超级管理员审批，同时保留此前已领取的客户权益、已确认预订及审计留痕。 |
<!--TABLE_END-->
