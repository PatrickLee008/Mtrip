# 模块01:后端共享组件包(backend/shared)

状态:已完成 | 进度:100% | 依赖:无 | 更新时间:2026-07-28

## 目标

为所有 Hyperf 微服务提供统一的基础能力包 `mtrip/shared`(Composer 本地 path 仓库引入),保证响应格式、鉴权、数据隔离、审计口径全平台一致。

## 任务清单

- [x] Composer 包骨架(composer.json、PSR-4 自动加载 `Mtrip\Shared\`)
- [x] 统一响应封装 Result:`{code, message, data, timestamp}` + 分页结构 `{list, total, page, pageSize}`
- [x] 错误码常量 ErrorCode(0 成功、40001 参数错误、40101~40103 鉴权、40301~40303 权限、40401、40901、42901、50001~50003)
- [x] 业务异常类 BusinessException + 全局异常处理器 AppExceptionHandler
- [x] JWT 工具(签发/校验/刷新,HS256,配置化过期时间)
- [x] 管理端鉴权中间件 AdminAuthMiddleware(解析 JWT → 注入管理员上下文)
- [x] RBAC 权限校验注解/中间件 PermissionMiddleware(按钮权限标识如 sys:admin:add)→ 实现为 #[Permission] 注解 + PermissionAspect 切面
- [x] 站点数据隔离:AdminContext(admin_id/site_id/role)+ 查询自动过滤 site_id 的模型基类 BaseModel
- [x] 客户端签名校验中间件 ClientSignMiddleware(ClientId + Sign + 时间戳防重放,QPS 限流、IP 白名单、过期校验)
- [x] 操作审计日志中间件 OperationLogMiddleware(写 sys_operation_log,记录修改前后数据)
- [x] 接口调用日志中间件 ApiAccessLogMiddleware(移动端全量日志,敏感参数脱敏)
- [x] AES-256 加解密工具 CryptoHelper(密钥类字段存储)+ 脱敏工具 MaskHelper(手机号/邮箱/密钥/银行卡)
- [x] 雪花ID/订单号生成器(站点编码+日期+时间戳+随机数)
- [x] 软删除、UTC 时间、decimal 金额处理约定统一在 BaseModel 落地

## 验收标准

- 各服务 composer require 后即可使用统一响应与中间件
- 单元测试覆盖 JWT、签名校验、脱敏、订单号生成
