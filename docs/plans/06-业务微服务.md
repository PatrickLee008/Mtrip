# 模块06:业务微服务(backend/services 7个业务服务)

状态:已完成(联调归模块08) | 进度:100% | 依赖:模块01、模块03 | 更新时间:2026-07-28

## 目标

按微服务架构在 `backend/services/` 下建立 7 个业务服务,首期完整实现商户、商品、订单三大核心,其余服务建立骨架 + 核心列表接口。

## 服务与优先级

| 服务 | 职责 | 首期范围 |
|------|------|---------|
| merchant-service | 商户入驻 + 供应商 | ★完整实现 |
| goods-service | 酒店/门票商品、分类、库存、审核 | ★完整实现 |
| order-service | 订单、状态机、退款、核销 | ★完整实现 |
| finance-service | 分账、结算、提现、流水、税费 | 骨架+资金流水/总览接口 |
| user-service | C端用户、会员、反馈 | 骨架+用户列表/详情接口 |
| marketing-service | 优惠券、活动、Banner、积分 | 骨架+优惠券 CRUD |
| payment-service | Stripe/PayPal、回调 | 骨架+渠道抽象接口 |
