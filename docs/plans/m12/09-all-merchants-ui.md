## 数据口径

1. 业务类型来自同站点未删除入驻申请的business_types及业务单元business_type，合并去重。支持酒店、餐厅、航空公司、租车、景点的目录展示和筛选；没有入驻申请的旧商户才回退旧分类（酒店/景点）。餐厅商品、履约及运营功能仍未开放。
2. 新增merchant_info.commission_plan，可选vip/premium/standard。历史及未设置记录为NULL，显示“未配置”；不从is_vip或佣金比例推断，也不批量赋值。详情佣金设置可显式选择档位，原commission_rate和settlement_cycle独立保留；旧调用不传commissionPlan时保留原档位。后端校验枚举，沿用merchant:list:edit与站点隔离。
3. 验证状态独立展示：status=0待验证、6待重交、2已拒绝、1/3/4已通过。暂停/黑名单不把已通过显示为验证失败。旧注销记录缺乏可靠验证快照时显示“未知”，不伪造已通过。
4. 账户状态优先显示有效黑名单，其次3活动中、4已暂停、5已注销，其余未启用。卡片受关键词、类型及当前管理员站点范围约束，独立于分页和所选状态；活动/暂停计数排除黑名单。全部还包含未启用等状态，因此不一定等于其余三卡之和。
5. 最后登录取同站点、未删除商户账号的最近成功登录时间，与商户表已有时间取较新值；列表排序和详情采用同一口径。无记录显示破折号，不将模拟会话当成商户登录。
6. 关键词补充工商注册号匹配，原名称、ID、邮箱、完整电话索引等搜索保留。导出列同步为当前表格语义，保留既有最多200条的导出限制，本轮不扩展大批量导出。
