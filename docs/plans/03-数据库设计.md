# 模块03:数据库设计(database)

状态:已完成 | 进度:100% | 依赖:无 | 更新时间:2026-07-28

## 目标

按功能设计文档第五部分规范输出全套 MySQL 8.0 DDL 与种子数据,按服务分目录存放,可一键初始化。

## 目录约定

```
database/
├── init/00-create-databases.sql     # 建库(mtrip_system/mtrip_business 等)
├── system/    # sys_* 系统表
├── merchant/  # merchant_*、supplier_*
├── user/      # user_*
├── goods/     # goods_*、hotel_*、ticket_*、库存日历
├── order/     # order_*(含分表说明)
├── finance/   # finance_*
├── marketing/ # marketing_*
└── seed/      # 初始化种子数据
```

## 设计规范(强制)

utf8mb4/utf8mb4_unicode_ci;表名模块前缀;id BIGINT UNSIGNED AUTO_INCREMENT;所有表含 created_at/updated_at/deleted_at;业务表含 site_id;金额 decimal(12,2);状态 tinyint+枚举注释;索引命名 idx_/uk_;订单、流水、接口日志按月分表(单表<500万)。
