## 目标

实现一级菜单 1~3(系统管理、系统日志、系统配置)全部页面,采用列表模板 + 表单/抽屉模板。

## 任务清单

### 系统管理
- [x] 管理员管理：列表(筛选：账号/站点/状态)、新增/编辑弹窗、重置密码、启停、批量操作、登录记录抽屉
- [x] 角色管理：列表、新增/编辑、权限分配(左侧菜单树勾选 + 按钮层级)、查看绑定管理员
- [x] 菜单管理：树形表格、新增菜单/按钮、排序、显隐、删除校验
- [x] 系统操作日志：列表筛选、详情弹窗(修改前后数据对比)、导出；顶部常驻「日志不可手动删除」提示

### 系统日志
- [x] 后台操作日志页(复用上，OplogPanel 共享面板)
- [x] 接口调用日志页：多条件筛选、详情脱敏展示、统计卡片(调用量/异常/平均耗时/TOP接口)、导出

### 系统配置
- [x] 全局参数配置：分 Tab 表单(平台基础/安全策略/上传限制/客户端&日志)，按 value_type 渲染控件、仅提交变更项、重置默认、Logo 预览
- [x] 站点配置：列表筛选、新增/编辑(基础+本地化+联系人)、启停、删除校验提示、差异化配置抽屉(local/page/operate/push 四组)
- [x] 文件存储管理：配置列表(密钥掩码、编辑留空保留)、设默认、文件库(图片预览/删除)；连通测试留至模块08
- [x] 支付渠道管理：渠道 CRUD(Stripe/PayPal)、启停、超管跨站点复制；回调测试留至模块08
- [x] 国际短信配置：渠道(Twilio/MessageBird)/模板(${var} 占位)/发送日志 三 Tab；发送测试留至模块08
- [x] Google 地图配置：按站点 upsert(非分页)、缩放 1-20、区域限制；接口测试留至模块08
- [x] 客户端密钥管理：列表(Secret 脱敏)、新增(明文 Secret 仅展示一次+复制)、重置密钥高危必填备注、调用统计抽屉
- [x] 客户端接口权限模板：列表、新增(白/黑名单，apiList 每行一条以 / 开头)、绑定客户端抽屉

## 通用要求

- 列表统一:分页、筛选、导出、批量操作、无权限按钮隐藏(v-perm)
- 高危操作(重置密钥、删除站点)二次确认 + 必填备注
- 密钥类字段脱敏组件展示,仅超管可查看明文
