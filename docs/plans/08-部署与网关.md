## 恢复联调清单(Docker 就绪后按此执行)

1. `cd deploy; cp .env.example .env; docker compose up -d --build`(首次构建含 composer install,较慢)。
2. 逐容器看健康:`docker compose ps`;单服务日志 `docker compose logs -f system-service`。
3. 网关链路:`curl -X POST http://localhost:8080/api/v1/admin/auth/login`(无参报参数错误 JSON 即通)。
4. admin-web `npm run dev` → 登录(种子账号见 database/seed/01-admin-role.sql)→ 动态菜单 → 各业务页 CRUD → 统计大屏。
5. client-app `npm start` 冒烟 /api/v1/app/*(站点/商品/登录)。
6. 验证 ClientSignMiddleware 签名链路与限流/错误 JSON 格式;修复联调发现的问题后,本模块升 100%。
