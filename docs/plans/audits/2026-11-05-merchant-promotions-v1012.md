## 配置与生效范围

后台现有“站点配置 → 运营”分组新增三项（金额单位沿用站点币种）：

| 键 | 有效范围 |
| --- | --- |
| `merchant_promotion_max_percent` | 大于 0、小于 100 的有限数字，表示立减百分比上限 |
| `merchant_promotion_max_amount` | 大于 0 的有限数字，固定优惠金额上限 |
| `merchant_promotion_min_payable_percent` | 大于 0、不超过 100 的有限数字，官方房价最低应付比例 |

当前迁移只写空配置；必须由平台填写正式值，方可保存/启用商户促销。站点时区读取 `sys_site.timezone`（既有空值回退 UTC）。新站点也必须补齐这些配置，服务端始终按缺失阻断。

三条新增迁移通过标准脚本本机执行；从已执行 51/待执行 3 变为已执行 54/待执行 0。通过 `deploy/mtrip.sh` 重启 marketing-service、marketing-service-app、order-service、order-service-app，脚本同步刷新网关。前端 5174 热更新生效，未发布 8091、未部署远端、未提交或推送。
