## 实施与验收计划

- [x] 数据与服务：在现有模板表标记物业专属版本及来源模板。每次配置创建不可变的独立版本，绑定当前申请物业；公共模板、其他申请与物业不受影响。最终批准沿用现有模板 ID 继承机制。
- [x] 门禁与历史：基础注册通过后可配置。首次提交后普通配置锁定；显式变更必须填写原因，只将目标物业恢复草稿、要求重新提交。校验站点、业务类型、文件类型唯一性及模板版本。移出要求的文件软归档，物理文件/版本保留，重新纳入时恢复。
- [x] 界面：当前业务显示模板名称、选择器、预览及编辑按钮；已提交显示锁定说明与变更要求入口。弹窗明确只影响当前物业，支持文档名称、增删及必填编辑（类型标识内部维护）；处理取消、失败、切换申请及过期响应。
- [x] 验证：先运行缺失能力回归得到失败证据，再补齐服务；隔离库覆盖站点/物业隔离、独立版本、并发、上传保留、审核中变更与重提、最终批准门禁。运行现有入驻回归、真实 SFC 交互、后台类型检查/构建、迁移检查及浏览器走查。

## 边界

复用 merchant:onboarding:kyc 权限，不新增公共模板管理模块，不修改基础注册、签署、逐文件审核和最终创建正式实体的顺序。不发送通知或改写真实申请。旧流程继续兼容。公共模板选项排除物业专属版本，避免其他流程自动选到申请内编辑的清单。

## 实现结果

- 新增模板选项与物业配置接口；继续复用已有权限键与站点边界。`PropertyKycTemplate.vue` 按原型展示模板下拉、预览与紫色编辑按钮，编辑弹窗只调整当前物业的名称、文件项和必填标志，内部文件标识不暴露给运营。
- 首次提交后只能使用带原因的“变更要求”。目标物业恢复 draft；保留的有效文件递增生命周期版本并重新待审，新旧 revision 与审核事件保留；拒绝／过期文件不会被变更自动置为有效。主体、其他物业及公共模板不变。
- 自动分配、公共候选及旧流程按业务类型的兜底查找均排除私有版本。正式物业继承该申请物业绑定的模板版本，无需改变最终批准事务。
- 为配置／上传／审核／到期处理统一入驻锁顺序；审核汇总改用当前读取，消除双连接旧快照造成“文件全过但物业仍审核中”的问题。独立只读审查已复核两项并发修复，无剩余重要问题。
- 实际候选来自启用公共模板；不复制原型的模拟通知、混合主体／物业材料或未确认的业务清单，不新增公共模板库管理模块。
