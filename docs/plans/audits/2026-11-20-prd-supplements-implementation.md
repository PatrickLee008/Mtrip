## 操作入口与发布内容

- 用户档案 → 账户注销 → 提交申请 → 超级管理员审批 → 财务经办 → 另一位财务复核 → 用户在 App 确认 DELETE。
- 统计报表 → 财务报表 → 钱包余额作废报告。
- 注销策略中可设置后续审批的有效期和生效时间。余额门槛仅保存配置及历史；正数余额仍需完整审批，不自动免审或作废。
- 旧版仅超管批准的记录不自动取得财务许可；需要重新提交新流程。
- 非超管账户需分配相应列表、经办、复核、报表或导出权限。后端 Permission、前端 v-perm、菜单种子和菜单迁移一致。

生产所需新增迁移：

1. `V20261120100000__account-deletion-finance-controls.sql`：审批扩展字段、策略/历史表和菜单权限。
2. `V20261120100100__multi-hotel-checkout-sessions.sql`：结算会话及截止时间。

按现有 Ops/自动部署的迁移流程先扩展结构，再发布 user-service、order-service、admin-web 和 client-app。没有直接修改生产数据库，也没有在开发业务库运行新增迁移。迁移可重复执行；测试使用临时隔离库。
