# 模块09:移动端微服务(C端 /api/v1/app/* 接口)

状态:已完成 | 进度:100%(Docker联调归模块08) | 依赖:模块01、模块03 | 更新时间:2026-07-28

## 目标

按技术方案V1微服务拆分,为 C端 Expo 客户端提供 `/api/v1/app/*` 接口。
与管理端(模块06)的关系:**同一业务微服务同时承载双前缀路由**,业务上通过路由前缀 + 鉴权中间件区分,数据模型完全复用。

## 服务归属与公用说明(核心结论)

| 服务 | 管理端路由 | 移动端路由 | 归属说明 |
|------|-----------|-----------|---------|
| system-service(已有) | /api/v1/admin/sys/* 等 | /api/v1/app/site/*(公开站点) | 管理端专属,仅补充 C端公开站点列表/配置接口 |
| user-service(新建) | /api/v1/admin/user/*(模块06补) | /api/v1/app/auth/*、/api/v1/app/user/* | 移动端为主:C端注册/登录/JWT/个人中心;管理端用户管理后续同服务补充 |
| goods-service(公用) | /api/v1/admin/goods/*(模块06) | /api/v1/app/goods/* | **公用**:管理端商品 CRUD/审核,移动端浏览/搜索/详情/价格日历,同库同模型 |
| order-service(公用) | /api/v1/admin/order/*(模块06) | /api/v1/app/order/* | **公用**:管理端订单管理/退款审核,移动端下单/取消/退款申请/核销码 |
| payment-service(公用) | 对账/渠道管理(模块06) | /api/v1/app/pay/* | **公用**:本期在 order-service 内提供 mock 支付,正式 Stripe/PayPal 拆到 payment-service |
| marketing-service(公用) | 优惠券 CRUD(模块06) | /api/v1/app/marketing/* | **公用**:Banner/领券/我的券,本期骨架列入模块06 一并实施 |
| merchant-service / finance-service | 管理端专属 | 无 | 移动端不直接访问,店铺信息经 goods-service 冗余输出 |

## 鉴权与隔离约定

- C端登录态:JWT(HS256,与后台同密钥),claims 含 `aud=app`、`user_id`、`site_id`;
  `UserAuthMiddleware` 校验 `aud`,拒绝后台 Token 混用,注入 `UserContext`
- 站点隔离:请求头 `X-Site-Id`(游客可用),登录后以 Token 内 site_id 优先;所有查询强制 site_id 过滤
- 网关层客户端签名(X-Client-Id/X-Sign,ClientSignMiddleware)在模块08 部署时启用,开发期可关
- 响应格式复用 `Result::success/page/error`,错误码复用 `ErrorCode`
