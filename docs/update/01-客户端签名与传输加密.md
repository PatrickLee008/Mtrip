# 专项升级 01:客户端签名与传输加密

> 日期:2026-07 | 状态:已上线验证 | 影响范围:backend/shared、8 个微服务、deploy、client-app、admin-web

## 1. 背景与目标

- app 全量接口此前无客户端鉴权,任何人拿到网关地址即可裸调
- 登录/注册等敏感接口明文传输账号密码,请求日志存在泄露面
- 利用 admin 后台已有「配置→客户端管理」(sys_client)下发的 ClientSecret,为移动端增加**请求签名**;对关键接口增加**请求体加密**;admin-web 登录同样加密

## 2. 总体设计

### 2.1 签名(app 全量接口)

- 生效范围:所有 `/api/v1/app/*` 路径(中间件全局注册,其余路径直接放行)
- 算法:`X-Sign = hex小写( HMAC-SHA256( clientId + METHOD大写 + path + timestamp + nonce, ClientSecret ) )`
  - `path` 为纯路径,**不含 query**
  - `timestamp` 为 Unix **秒**
- 请求头:`X-Client-Id` / `X-Timestamp` / `X-Nonce` / `X-Sign`
- 时间窗口:超过 `MTRIP_SIGN_TTL`(默认 3600 秒)提示「请求已过期,请检查设备时间」
- 防重放:nonce 写入 Redis(`SET NX EX=签名TTL`),重复即拒绝
- 保留 sys_client 原有能力:状态/过期时间/IP 白名单/QPS 限流/接口权限模板

### 2.2 传输加密(关键接口)

- 算法:AES-256-CBC,`key = sha256(密钥串) raw 32字节`(兼容前端 crypto-js;存储层加密仍用 CryptoHelper 的 AES-256-GCM,不混用)
- 请求格式:body 整体加密为 `{"payload": "base64(IV16字节 + 密文)"}` + 请求头 `X-Encrypted: 1`
- 密钥选择:
  - `/api/v1/app/*`:ClientSecret(由 `X-Client-Id` 反查 sys_client,Redis 缓存 600s)
  - `/api/v1/admin/*`:独立配置 `MTRIP_ADMIN_AES_KEY`(与 admin-web `VITE_LOGIN_AES_KEY` 同值)
- 强制加密名单(默认,可被各服务 `config/autoload/mtrip.php` 的 `encrypt_paths` 覆盖):
  - `/api/v1/app/auth/login`、`/api/v1/app/auth/register`、`/api/v1/admin/auth/login`
- 语义:带 `X-Encrypted: 1` 的密文**始终**解密;`MTRIP_PAYLOAD_ENCRYPT` 开关只控制「名单内接口是否必须加密」

### 2.3 调试开关

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `MTRIP_CLIENT_SIGN` | true | app 签名校验开关,**生产必须 true**;本地 curl 调试可临时 false |
| `MTRIP_SIGN_TTL` | 3600 | 签名时间窗口(秒),nonce 缓存 TTL 同步 |
| `MTRIP_PAYLOAD_ENCRYPT` | true | 强制加密名单开关,**生产必须 true** |
| `MTRIP_ADMIN_AES_KEY` | — | admin 登录加密密钥,生产更换强随机串 |

## 3. 改造清单

### 3.1 后端共享包(backend/shared)

| 文件 | 变更 |
| --- | --- |
| `src/Middleware/ClientSignMiddleware.php` | 改造:限定 `/api/v1/app/*`、`MTRIP_CLIENT_SIGN` 开关、TS_TOLERANCE 硬编码改读 `MTRIP_SIGN_TTL`、密钥解析抽取到 Resolver |
| `src/Support/ClientSecretResolver.php` | 新建:sys_client 查询(system 连接)+ Redis 缓存 600s + AES-GCM 解密明文 Secret |
| `src/Support/TransportCipher.php` | 新建:AES-256-CBC 加/解密(key=sha256(secret),IV 随机前置,base64) |
| `src/Middleware/PayloadDecryptMiddleware.php` | 新建:X-Encrypted 密文还原为 parsedBody 并 `Context::set` 回写(控制器零改动);强制名单校验 |

### 3.2 8 个微服务

`config/autoload/middlewares.php` 在 `RequestLogMiddleware` 后统一追加两个中间件(system/user/goods/order/merchant/finance/marketing/payment)。控制器无需任何改动。

### 3.3 部署(deploy/)

- `docker-compose.yml` x-hyperf-env 新增上表 4 个变量
- `.env` / `.env.example` 新增「接口安全」配置段
- `openresty/conf.d/mtrip.conf`:admin 与 app 两个 location 的 `Access-Control-Allow-Headers` 追加 `X-Encrypted`

### 3.4 client-app(移动端)

- 安装 `crypto-js`
- `src/utils/sign.ts` 新建:nonce 生成、HMAC-SHA256 签名、AES 加密(随机数优先 Web Crypto,Hermes 回退 Math.random)
- `src/api/request.ts`:拦截器对 `/api/v1/app/*` 自动附加 4 个签名头(`X-Timestamp` 由毫秒改为**秒**);新增 `postEncrypted()`
- `src/api/user.ts`:`apiLogin` / `apiRegister` 改用 `postEncrypted`
- `.env` 新增 `EXPO_PUBLIC_CLIENT_ID` / `EXPO_PUBLIC_CLIENT_SECRET`(未配置时不附加签名头,配合后端开关关闭调试)

### 3.5 admin-web(管理后台)

- 安装 `crypto-js`
- `src/utils/crypto.ts` 新建 `encryptPayload`;`src/api/auth.ts` 登录在 `VITE_LOGIN_AES_KEY` 配置时发送加密 payload
- `.env.development` 配置 dev 密钥;`.env.production` 留空占位(构建时注入)

## 4. 密钥配置流程

1. admin 后台「配置→客户端管理」新建客户端(Secret 仅创建/重置时展示一次)
2. 复制 clientId/Secret 填入 client-app `.env` 的 `EXPO_PUBLIC_CLIENT_ID/SECRET`,重启 Expo(`npm start -- --clear`)
3. admin 登录加密:`deploy/.env` 的 `MTRIP_ADMIN_AES_KEY` 与 admin-web `VITE_LOGIN_AES_KEY` 保持同值

## 5. 验证结果(全部通过)

验证脚本:`powershell -ExecutionPolicy Bypass -File deploy/test-sign.ps1`

| 用例 | 结果 |
| --- | --- |
| 无签名裸调 `/api/v1/app/site/list` | 401 `40103 客户端鉴权失败` |
| 明文调 admin 登录 | 400 `该接口要求加密传输` |
| AES 加密调 admin 登录 | 200 拿到 token |
| 创建客户端 | 200 返回一次性 Secret |
| HMAC-SHA256 签名调 app 接口 | 200 |
| 时间戳超窗口(-2h) | 401 `请求已过期,请检查设备时间` |
| 签名 + AES 加密调 app 登录 | 解密成功进入业务校验 |
| 明文(无 X-Encrypted)调 app 登录 | 400 `该接口要求加密传输` |
| 两开关设 false 重建 → 明文恢复可用 → 恢复 true | 回归通过 |

日志核验:加密接口 request.log 中 params 仅为密文 payload,明文密码不落盘;非加密接口密码字段照常脱敏。

## 6. 注意事项与坑

- **RequestLogMiddleware 在解密前记录**:加密接口日志 params 为密文,属预期脱敏行为
- **X-Timestamp 必须为秒**:前端曾用毫秒,已统一改秒;PowerShell 5 `Get-Date -UFormat %s` 按本地时间计算(偏差 8h)会误报「请求已过期」,脚本需用 `[DateTimeOffset]::UtcNow.ToUnixTimeSeconds()`
- **新增自定义请求头需扩网关 CORS**:`Allow-Headers` 已补 `X-Encrypted`,后续再加头需同步修改 mtrip.conf 并 reload
- **env 变更需重建容器**:`docker compose up -d`(仅重启不会重新注入环境变量)
- **生产要求**:两个开关必须 true,`MTRIP_ADMIN_AES_KEY` 更换强随机串,ClientSecret 不入库明文(AES-GCM 加密存储)
