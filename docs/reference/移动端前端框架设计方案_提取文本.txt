Mtrip海外旅游平台-移动端前端框架设计方案（开发落地版）
一、方案总览
1.1 适用范围
本方案为 Mtrip 海外旅游平台移动端（iOS APP、Android APP、移动端H5）统一前端框架规范，基于项目最终定型技术栈搭建，用于指导移动端项目初始化、目录规范、公共能力封装、业务开发、适配海外多站点、多语言、GDPR合规、海外支付与推送场景，为前后端协同开发提供统一标准。
1.2 核心技术栈（最终定型、不可变更）
整体架构：Expo 51+ + React Native + TypeScript
配套核心依赖（项目唯一选型）：
语言：TypeScript（全量类型约束，杜绝隐式任意类型）
基础框架：Expo 51+（一套代码编译 Android / iOS / H5）
状态管理：Zustand（全局状态、站点状态、商户状态、用户信息统一管理）
路由管理：React Navigation 6
网络请求：Axios（统一拦截、鉴权、脱敏、异常处理）
国际化：i18next + react-i18next（多语言、多时区、多币种）
地图服务：Google Maps（海外专属，定位匹配站点）
消息推送：FCM + APNs（海外合规推送）
支付能力：Stripe、PayPal 官方 SDK
打包部署：EAS Build 云端打包、Expo Web 静态H5部署
1.3 框架核心设计目标
统一多端能力：一套代码兼容 APP/H5，抹平两端差异
适配平台核心能力：多站点切换、商户店铺隔离、数据权限隔离
海外合规闭环：GDPR隐私授权、数据脱敏、多语言多时区多币种
高可维护性：标准化目录、统一封装、强TS类型、统一编码规范
高稳定性：统一请求拦截、错误捕获、日志上报、防崩溃处理
二、全局基础配置规范
2.1 环境区分配置
项目内置三套环境，通过环境变量区分，Expo 原生适配：
开发环境（dev）：本地调试、联调后端测试接口
测试环境（test）：测试验收、全功能回归
生产环境（prod）：正式上线、海外CDN部署、EAS打包发布
核心环境变量统一约束：
API_BASE_URL：后端微服务接口地址
SITE_ID：默认初始化站点ID
PLATFORM_ENV：环境标识 dev/test/prod
ENABLE_LOG：是否开启本地日志打印
ENABLE_MOCK：是否开启模拟数据
2.2 跨域解决方案（H5端专属）
APP端无跨域问题，仅移动端H5存在跨域限制，采用项目标准化方案：
开发阶段：Expo Web 配置代理转发，解决本地跨域
生产阶段：依托 Cloudflare CDN + OpenResty 网关统一域名转发，后端配置跨域白名单，永久解决线上跨域
全局禁止前端跨域暴力破解，所有接口请求统一走网关入口
2.3 多端区分规范（APP / H5）
封装全局统一方法，业务层无感区分，底层自动适配：
全局判断API
isApp()：判断是否为原生APP端（iOS/Android）
isH5()：判断是否为移动端网页端
getClientType()：返回客户端类型 app-h5 / app-ios / app-android
多端差异化适配规则
推送能力：仅APP端启用FCM/APNs推送，H5端禁用
支付能力：两端统一调用封装方法，底层自动适配对应端SDK
导航栏、状态栏：APP端适配原生状态栏，H5端适配浏览器顶部栏
本地存储：统一封装Storage，抹平AsyncStorage与浏览器Storage差异

五、网络请求全局规范（核心）
5.1 请求统一封装规则
基于Axios全局单例封装，统一拦截、鉴权、脱敏、报错、日志上报，所有业务接口必须调用统一方法，禁止原生Axios请求。
5.2 全局请求头固定参数（强制）
所有接口自动携带，无需业务手动传入：
Authorization：用户登录Token
X-Site-Id：当前所属站点ID（多站点隔离核心）
X-Client-Type：客户端类型（app/h5）
X-Timestamp：时间戳
X-Lang：当前语言标识
5.3 请求拦截器能力
自动携带Token、站点ID，无Token拦截未登录请求
请求参数自动脱敏（手机号、邮箱、密钥），符合GDPR规范
统一加载动画控制，避免重复loading
重复请求防抖拦截，防止短时间重复提交
5.4 响应拦截器能力
统一状态码解析：成功、失败、Token过期、权限不足、站点禁用
Token过期自动清除登录态、跳转登录页
全局错误Toast提示，无需业务单独处理
异常接口自动写入前端日志，用于问题追溯
敏感数据响应自动脱敏展示
5.5 接口请求方法规范
get：查询类接口（列表、详情、统计）
post：新增、提交、下单、核销
put：编辑、修改信息
delete：删除操作
六、登录与鉴权体系规范
6.1 登录流程标准化
用户输入手机号/密码/验证码登录
请求登录接口，获取 Token、用户信息、会员等级、绑定站点
Zustand全局存储用户状态、登录状态、默认站点信息
本地加密存储Token，持久化登录态
自动携带站点ID，初始化对应站点的货币、语言、时区
6.2 鉴权规则
未登录用户：禁止访问个人中心、订单、核销、支付等权限页面，自动跳转登录
Token过期：前端自动清空登录态，弹窗提示重新登录
站点禁用：自动拦截当前站点访问，提示站点暂停运营
权限不足：拦截接口请求，提示无操作权限
6.3 退出登录规范
清空本地Token、用户缓存、站点缓存
重置Zustand全局状态
跳转首页/登录页
记录退出登录日志
