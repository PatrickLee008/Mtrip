Mtrip海外旅游SaaS管理后台UI设计方案（对标携程eBooking+美团商家后台，基于Ant Design Vue Pro）
一、方案总览
1.1 设计定位
对标携程 eBooking 旅游商家后台（专业旅游 OTA、多站点房源、财务结算、数据经营看板）+ 美团商家管理后台（高效商户审核、订单流水线、营销可视化、轻量化操作），结合项目多商户 SaaS、海外 GDPR 合规、多站点隔离、客户端鉴权、财务分账核销专属业务，基于技术栈Vue3 + Vite + TS + Ant Design Vue Pro搭建统一 UI 设计系统，兼顾平台超级管理员、站点运营、财务、商户运营多角色操作效率，适配海外多货币、多时区、多语言场景。
1.2 核心设计原则（融合携程 + 美团 B 端优势）
业务优先，轻量化信息层级携程优势：数据专业分层、房源 / 订单全流程可视化；美团优势：待办红点提醒、批量快捷操作、筛选器轻量化；所有页面优先展示待处理工单、预警数据、核心营收指标，减少无效滚动。
多角色数据隔离视觉区分超级管理员（全平台）、站点管理员（单站点）、财务、商户运营菜单、数据面板做视觉标识，跨站点数据自动置灰隐藏，符合 GDPR 数据隔离规范。
强审计、高可信财务视觉体系资金、订单、核销、日志模块采用携程金融级数据展示规范，金额分级着色、流水永久归档视觉提示、敏感信息自动脱敏展示。
国际化适配一套 UI 支持多语言、多时区、多货币符号自动切换，表单、图表、导出文案动态适配。
双主题模式亮色（默认运营）+ 暗色（数据大屏夜间值守），一键切换，兼容 Ant Design Vue Pro 原生主题能力。
权限驱动 UI 渲染无权限按钮、Tab、操作入口自动隐藏，后端下发权限标识，前端不硬编码，杜绝越权视觉漏洞。
1.3 技术适配基础
栅格系统：12 列弹性栅格，基准画布 1440*900，兼容 1366/1920 办公显示器
布局底座：ProLayout 标准顶部 Header + 左侧可折叠侧边菜单 + 主体内容区（携程 EBK 同款经典布局，美团商家后台主流布局）
组件库：全量复用 Ant Design Vue Pro 业务组件，扩展旅游行业定制组件（房型日历库存、核销码卡片、分账流水面板、站点树形选择器）

三、全局标准布局方案（顶部 Header + 左侧侧边栏 + 内容区）
3.1 顶部 Header（高度 48px，全局固定置顶）
分 5 个区域从左至右：
Logo &amp; 系统名称区Mtrip 海外旅游平台管理后台，深色侧边栏白色 Logo，浅色侧边栏蓝色 Logo；hover 可快速跳转数据大屏首页。
全局快捷搜索支持全局检索：商户 ID、订单号、用户手机号、商品名称、站点名称，一键跳转到对应详情页（携程 EBK 核心功能）。
站点快速切换下拉（SaaS 核心）超级管理员可下拉切换全平台 / 任意站点；站点管理员仅显示当前站点，置灰不可切换；切换后页面数据自动过滤，同步更新面包屑、筛选条件。
全局快捷功能区
待办消息铃铛：红点数字提示（待审核商户、待退款订单、低库存预警、核销异常），点击弹窗快捷处理
主题切换：亮色 / 暗色一键切换
多语言切换：中文 / 英文（预留多语种扩展）
客服帮助入口：操作文档、工单反馈
个人账号区管理员头像、账号名称、所属角色；下拉菜单包含：个人设置、修改密码、操作日志查看、退出登录。
3.2 左侧侧边导航栏（宽度 256px，可一键折叠为 64px 图标栏）
菜单数据源：后端动态下发，根据管理员角色自动过滤无权限菜单，完全匹配文档 12 级一级菜单结构：系统管理、系统日志、系统配置、商户管理、供应商管理、C 端用户、商品、订单、财务、营销、数据统计、核销管理
菜单交互规则（融合美团手风琴 + 携程分层）
一级菜单点击展开 / 折叠二级子菜单（手风琴模式，仅展开当前分类）
当前页面菜单蓝色高亮左侧竖线标识
带待办数量的菜单右侧橙色数字角标（如商户管理 (12) 代表 12 条待审核商户）
折叠状态仅展示图标，hover 悬浮弹出完整菜单名称 tooltip
底部固定栏：侧边栏最下方常驻版本号 V1.0、当前登录站点、权限身份标识（超级管理员 / 站点运营）
3.3 主体内容区（PageContainer，Antd Pro 标准容器）
页面顶部统一内置：
面包屑导航：自动匹配菜单层级，支持点击回退上级页面
页面标题 + 操作按钮组（页面级新增、批量导出、批量审核、刷新）
筛选器区域（统一横向卡片筛选，对标美团订单列表轻量化筛选）主体内容分三类页面模板：数据看板页、列表表格页、详情表单页

五、核心业务模块页面 UI 专项设计（匹配文档 9 大业务 + 底层系统模块）
5.1 底层系统模块 UI（权限、站点、存储、客户端鉴权）
角色 &amp; 菜单权限管理左侧树形菜单勾选面板，右侧绑定管理员列表；树形节点区分一级菜单 / 页面 / 按钮权限，无权限置灰不可勾选，对标 RBAC 三级权限可视化。
多站点树形配置树形结构展示全球站点层级（欧洲→法国→巴黎），站点停用后整行灰色置灰，操作按钮锁定；站点详情卡片展示本地化货币、税率、抽佣比例。
客户端密钥管理ClientId 明文展示，ClientSecret 脱敏隐藏；重置密钥橙色高危按钮，弹窗提示重置后移动端接口立即失效；QPS 限流、IP 白名单表单输入框分隔展示多 IP。
双审计日志页面（系统操作日志 + 接口调用日志）表格内置「查看详情」按钮，弹窗展示修改前后数据对比；敏感参数自动灰色脱敏标注；日志无删除按钮，顶部文字永久提示「日志不可手动删除，定时归档」，满足 GDPR 审计。
5.2 商户 &amp; 供应商管理模块 UI
商户审核页面：资质图片卡片预览（营业执照、法人证件），审核意见输入框，驳回橙色 / 通过绿色双按钮；待审核商户菜单带橙色数字角标。
商户结算账户卡片：银行信息脱敏展示，SWIFT Code 单独分区，加密提示文字。
供应商供货商品列表：底价、供货分成两列分色展示，区分供应商成本与商户售价。
5.3 商品管理模块（酒店 / 门票核心）
酒店房型分时库存日历组件（携程 EBK 同款核心组件）横向日期、纵向房型矩阵，单元格展示售价、剩余库存；红色标低库存预警，支持批量框选日期改价、调库存。
景区票种管理：核销规则独立卡片，区分分时票 / 套票，核销次数限制高亮提示。
商品审核工作台：左侧待审核商品列表，右侧大图预览 + 信息编辑区，一键通过 / 驳回填写原因。
5.4 订单 &amp; 财务模块（金融级视觉，对标携程结算后台）
订单状态全流程进度条：待支付→已支付→待核销 / 待入住→已完成，退款 / 取消分支灰色虚线展示。
退款审核专用页面：自动计算可退金额高亮展示，退改规则悬浮提示，驳回记录永久留存。
财务分账总览卡片：平台佣金、商户实收、供应商成本三色区分；月度对账单导出蓝色主按钮，顶部提示「流水永久归档不可删除」。
税费配置 Tab：各国站点 VAT 税率表格，自动含税 / 不含税预览计算。
5.5 核销管理模块（线下终端管控）
核销设备状态卡片：绿色在线、灰色离线、红色故障，设备密钥重置高危操作弹窗确认。
核销日志表格：每条记录标注核销设备编号、操作员、核销时间，重复核销异常标红高亮。
后台手动核销弹窗：输入核销码校验，撤销核销需填写审批备注，操作日志永久记录。
5.6 营销活动模块（优惠券、限时活动）
优惠券卡片列表：直观展示满减 / 折扣面值、有效期、领取使用数据，未开始灰色、进行中蓝色、已结束灰色。
首页 Banner 配置可视化预览区，左侧配置表单、右侧实时预览站点 H5 首页效果。
六、交互体验规范（对标美团 + 携程高效操作）
待办驱动交互所有待处理工单（商户审核、退款、低库存、核销异常）全局红点角标，顶部铃铛一键聚合处理，无需逐层查找菜单。
批量快捷操作列表支持多选批量审核、批量上下架、批量导出、批量启停，减少重复单点操作（美团商家后台核心优势）。
草稿自动保存商品、商户编辑表单实时自动存草稿，刷新页面不丢失填写内容。
高危操作强阻断注销商户、重置密钥、批量退款、删除站点均弹出二次确认弹窗，强制输入备注原因，操作写入审计日志。
异步任务提示大数据导出、批量库存调整、报表生成右下角全局进度弹窗，完成后通知下载文件。

性能 UI 约束
表格分页默认 20 条，超 1000 条数据禁用前端全量渲染，强制分页 / 异步导出

安全 UI 约束
所有密钥、身份证、手机号前端强制脱敏，无入口一键展示全部明文（仅超级管理员单独弹窗）

合规 GDPR 视觉提示日志、用户数据页面顶部常驻浅色提示条：「用户数据按 GDPR 规范存储，支持导出 / 删除申请，操作永久审计」
响应式适配后台最小适配分辨率 1366*768；宽度不足时侧边栏自动折叠，表格横向滚动，表单自动纵向堆叠。
