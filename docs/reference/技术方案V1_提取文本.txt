Mtrip海外旅游项目完整版技术方案V1
一、项目总览
项目名称：Mtrip（海外旅游预订平台）
核心业务：海外酒店预订、境外景区门票预订、订单管理、海外支付、多币种结算
平台核心属性（新增）：多商户入驻平台、多区域/多城市站点架构，支持第三方酒店、景区商户入驻开店，按国家、区域、城市拆分独立站点运营，实现分站点流量、商品、订单、数据独立管控
产品形态：
C端：iOS APP / Android APP / 移动端H5（一套代码多端），支持多城市站点切换、商户店铺主页展示
B端：海外运营总后台（平台方）+ 商户独立后台（入驻商家），前后端完全分离
架构定位：
前后端完全分离
PHP 协程微服务高并发架构
适配海外服务器、海外支付、GDPR合规、全球访问
原生支持多商户SaaS入驻、多区域城市站点平台化架构
二、最终定型全套技术栈（无争议、最终版）
1. C端多端客户端（唯一选定：Expo）
框架：Expo 51+（React Native + TypeScript）
✅ 原因：唯一满足「一套代码打包 Android / iOS / H5」且适合海外商业项目的稳定方案
✅ 完全规避 uni-app 国内生态依赖、海外推送/地图残废问题
✅ 海外生态完美：FCM、GoogleMap、Stripe、PayPal、i18n 全部原生支持
✅ 原生适配平台属性：支持城市站点切换、商户店铺展示、多商户商品聚合、分站点内容隔离
C端核心技术明细
语言：TypeScript
UI体系：React Native 原生组件 + Expo生态
状态管理：Zustand（轻量、适合电商/旅游平台，支持站点、商户全局状态存储）
路由：React Navigation 6（支持站点路由隔离、商户店铺独立路由）
网络：Axios（统一拦截、JWT、异常处理，自动携带当前站点ID、商户ID）
地图：Google Maps（全海外适配，基于定位自动匹配当前城市站点）
推送：FCM + APNs（海外唯一稳定推送方案，支持按站点、按商户精准推送）
支付：Stripe、PayPal（海外主流，支持平台分账、商户独立结算）
国际化：i18next（多语言、多时区、多币种，适配不同区域站点本地化展示）
合规：GDPR隐私授权、用户数据可控，分站点数据隔离合规
打包：EAS Build 云端打包（无需本机原生环境）
H5部署：Expo Web 输出静态资源 + Cloudflare CDN，支持多站点域名/路径区分
平台专属能力：城市/区域站点切换、商户店铺主页、商户商品聚合筛选、分站点热门推荐、平台与商户权益隔离
2. 后端微服务（最终选定：Hyperf）
框架：Hyperf 3.1（Swoole协程微服务）
❌ 彻底放弃 Lumen：FPM架构扛不住旅游高峰期并发、无微服务、无分布式事务、无法集群扩容，且不支持多租户多商户架构扩展
✅ Hyperf是海外旅游平台项目最佳PHP后端：高并发、常驻内存、微服务、WebSocket、队列、秒杀库存天然支持，原生适配多商户SaaS、多区域站点平台化架构，支持数据隔离、分账结算、站点独立运营
后端微服务拆分（最终固定，新增平台专属服务）
用户中心服务（注册、登录、JWT、会员、用户合规数据、用户站点绑定）
平台站点服务（新增核心）：全球区域、国家、城市站点配置、站点状态管控、站点域名绑定、分站点流量隔离、站点参数配置
商户入驻服务（新增核心）：商户注册入驻、资质审核、商户权限、店铺配置、商户费率、结算账户管理、商户状态管控
酒店商品服务（酒店、房型、价格、库存、上架下架，绑定对应商户、对应城市站点）
门票商品服务（景区、票种、分时库存、核销规则，关联商户、归属站点）
订单核心服务（下单、锁库存、超时取消、退款、核销，自动归属站点+商户，支持平台抽佣、商户分账）
支付网关服务（Stripe/PayPal、多币种、汇率、对账、平台与商户分账结算、海外税费拆分）
消息推送服务（WebSocket实时订单推送 + FCM调度，按站点、商户精准推送通知）
后台权限服务（RBAC、菜单、角色、操作日志审计，区分平台超级管理员、站点管理员、商户管理员三级权限）
后端核心中间件（海外版 + 平台化适配）
数据库：MySQL8.0（海外云 RDS），采用单库多租户隔离方案，通过站点ID、商户ID实现数据逻辑隔离，支持后续分库分表扩容
缓存/锁：Redis7.0（库存防超卖、限流、缓存，分站点、分商户缓存隔离，避免数据冲突）
队列：RabbitMQ（订单削峰、异步任务、退款、超时关闭，支持站点、商户任务独立调度）
注册中心：Nacos（服务发现、统一配置，支持多环境、多站点配置差异化管理）
熔断限流：Sentinel（支持全局限流、单站点限流、单商户限流三级防护）
链路追踪：SkyWalking（精准定位各站点、各商户接口异常与性能问题）
存储：AWS S3 / Cloudflare R2（海外图片静态资源，资源归属站点、商户，支持独立资源权限）
通信：对外HTTP API、内部JSON-RPC微服务调用，平台内部服务互通，隔离各站点商户业务数据
后端平台化核心能力（多商户+多站点专属）
多站点架构：支持全球区域、国家、城市多级站点搭建，可独立配置站点域名、货币、语言、税费、运营规则、首页推荐内容
多商户SaaS能力：支持酒店、景区商户自主入驻，独立管理店铺商品、库存、订单、核销、结算，平台统一审核监管
数据隔离机制：所有商品、订单、用户、资金数据通过「站点ID+商户ID」双维度隔离，跨站点、跨商户数据互不干扰
分账抽佣体系：支持平台自定义各站点、各行业商户抽佣比例，自动完成订单分账、资金拆分、对账统计
分级权限体系：超级平台管理员（全权限）、区域站点管理员（单站点权限）、商户管理员（单店铺权限）三级权限隔离
3. B端运营管理后台（最终选定：Ant Design Vue Pro 开源免费版）
框架：Vue3 + Vite + TS + Ant Design Vue Pro（MIT免费商用）
✅ 完全免费、海外商用合法、无版权风险
✅ 适配酒店/门票/订单/财务/权限全套企业级后台能力
✅ 前后端完全分离，与Hyperf微服务完美对接
✅ 原生支持平台多角色、多站点、多商户管理体系，适配海外旅游平台运营场景
后台核心能力（新增平台专属功能）
动态RBAC权限、动态菜单，支持三级角色权限：平台总管理员、站点运营管理员、入驻商户管理员
平台站点管理（新增）：全球城市/区域站点新增、编辑、启停、域名配置、站点差异化参数设置、站点数据统计
商户入驻管理（新增）：商户资质审核、商户账号开通、费率配置、店铺管理、商户违规封禁、商户数据汇总
酒店/门票 CRUD、批量改价、上下架、库存管理，支持商户自主操作+平台审核管控
订单管理、退款审核、核销管理，支持按站点、按商户、按区域筛选统计
海外多币种财务统计、VAT税费展示，新增平台抽佣、商户分账、站点营收对账功能
Excel导入导出、数据大屏图表，支持全局、单站点、单商户数据可视化
多语言、多时区适配海外运营，适配不同区域站点本地化运营需求
完整操作审计日志（满足海外合规），记录各站点、各商户、各管理员操作行为
4. 网关 &amp; 运维 &amp; 部署架构（海外最终版）
API网关：OpenResty（Nginx+Lua）统一入口、限流、SSL、跨域、路由分发，支持按站点域名、商户路由精准分发请求
CDN：Cloudflare（全球加速、防DDoS、海外低延迟），支持多站点静态资源独立加速、区域智能调度
部署方式：Docker + K8s 容器化集群，支持按区域站点独立部署、弹性扩容，高峰期单站点独立扩容不影响全局
服务器区域：新加坡/美国/欧洲多节点按需部署（满足GDPR数据本地化），实现对应区域站点数据本地存储、合规隔离
监控体系：Prometheus + Grafana + SkyWalking，支持全局、单站点、单商户维度性能监控与异常告警
告警：Email / Slack（海外团队标准），支持站点故障、商户异常订单、资金对账异常精准告警
三、整套架构数据流（最终标准，平台化适配）
用户 Expo APP / H5 基于定位或手动选择，进入对应城市/区域站点
客户端自动携带当前站点ID、访问对应商户商品资源，发起接口请求
经过 Cloudflare CDN + OpenResty 网关，网关完成站点路由匹配、限流、安全校验
网关根据路径转发至对应 Hyperf 微服务，服务层通过站点ID+商户ID完成数据隔离
微服务执行：数据库查询、Redis锁、队列异步处理，下单时自动关联站点与商户，生成分账、抽佣数据
常规数据通过 JSON 返回，前端展示对应站点、商户的商品与订单信息
订单状态/核销消息通过 WebSocket 实时推送对应站点客户端、对应商户后台
平台总后台、站点运营后台、商户后台复用同一套服务API，通过权限区分操作范围，完成分级运营管理
