# Mtrip Ops 安全模型

## 默认策略

Mtrip Ops 默认只读:

- `host=127.0.0.1`
- `enableActions=false`
- 不直接暴露 Docker socket
- 不内置业务库写权限
- **全站需登录**(除 `/login` 与 `/public/*`)

生产环境必须放在内网、VPN、堡垒机或 SSH tunnel 后面,不要公网裸露。

## 账号体系

零依赖实现(只用 `node:crypto`),代码在 `src/auth.js`。

### 角色与权限

| 角色 | 权限键 | 可访问 |
|---|---|---|
| `viewer` 只读 | `view` | 总览、服务、日志、审计、计划文档、`/api/*` |
| `operator` 运维 | `view` `action` | 以上 + 发布页与全部白名单动作 |
| `admin` 管理员 | `view` `action` `admin` | 以上 + `/users` 账号管理 |

判定统一走 `can(user, permission)`,路由层**默认拒绝**;导航栏同时按权限隐藏入口,
但隐藏只是界面收敛,**真正的拦截在路由层**,两处都有。

### 口令与会话

- 口令用 `scrypt` 加盐哈希(每人独立 salt),校验走 `timingSafeEqual` 防时序侧信道;
  `data/users.json` 权限 `0600`,**不存明文**。
- 首次启动无账号时自动创建 `admin`,口令随机生成且**只在控制台打印一次**,
  不留可猜的默认口令(`./ops.sh logs` 可回看)。
- 会话是「进程内 Map + 32 字节随机 sid」,cookie `HttpOnly; SameSite=Strict`。
  sid 不可猜且只在服务端查表,故不再额外签名。
  **已知取舍:进程重启即全部登出**(会话不持久化)。
- 空闲 8 小时自动失效;角色与禁用状态每次请求回读 `users.json`,
  故改角色/禁用对目标用户的**当前会话立即生效**。
- 登录失败按「用户名+IP」计数,5 次锁 5 分钟;用户名不存在与口令错误返回**同一条提示**,避免账号枚举。
- 所有状态变更请求校验 CSRF token(`SameSite=Strict` 之外的第二道)。

### 防自锁

最后一个可用管理员不能被降级、禁用或删除;也不能删除当前登录的账号。

### 未覆盖

不做找回密码、2FA、OAuth/LDAP、会话持久化。真需要时应换成成熟方案而非在此扩写。

## 动作分级

| 级别 | 示例 | 最低角色 | 现状 |
|---|---|---|---|
| 只读 | 查看 health、日志、容器状态 | `viewer` | 允许 |
| 低风险动作 | `auto-deploy.sh --dry-run`、`mtrip.sh health`、`git status/fetch` | `operator` | 需 `enableActions=true` |
| 中风险动作 | 重启单服务、DB backup、`git pull --ff-only` | `operator` | 需 `enableActions=true` |
| 高风险动作 | **自动部署**(`auto-deploy.sh`)、**指定目标发布**(`auto-deploy.sh <target>`) | `operator` | 需 `enableActions=true` + 页面二次确认弹窗 |
| 未开放 | DB apply、`down -v`、正式环境灰度 | — | 不提供入口 |

高风险动作当前**未做审批/双人确认**,仅靠角色 + `enableActions` + 二次确认三道。
若要更严,后续可加「发布窗口」或「admin 二次批准」。

## 命令白名单

所有子进程执行必须满足:

- 使用 `execFile`,不用 shell 拼接。
- 命令名和参数由服务端白名单生成。
- 页面请求只传动作 ID,不传任意命令。
- stdout/stderr 和退出码写审计。

## 审计字段

已实现(`src/runner.js` 的 `appendAudit`,落 `data/audit.log`,`/audit` 页可视):

- [x] 操作人(`user`)
- [x] 来源 IP(`ip`)
- [x] 动作类型(`type`:`command-start` / `command-end` / `command-rejected`)
- [x] 目标服务(`payload.service`)
- [x] 命令参数(`command` / `args` / `cwd`)
- [x] 开始/结束时间(`at`)
- [x] 退出码(`code`)

待补:

- [ ] before/after git SHA
- [ ] stdout/stderr 摘要(当前只回显在页面,未入审计)

> 启用账号体系之前产生的历史记录没有 `user` / `ip`,页面显示为 `-`。
> `ip` 若经反代需在反代设置 `X-Forwarded-For`;该头可伪造,**仅用于审计展示,不作安全判定**。

## Docker 权限

直接挂载 `/var/run/docker.sock` 等同宿主 root 权限。后续如需 Docker Engine API,优先:

1. 使用 docker-socket-proxy 限制 API 能力。
2. 将重启/部署动作放到本地 runner,Web 只发白名单任务。
3. Web 进程用低权限用户运行。
